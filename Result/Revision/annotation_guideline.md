# 标注指南：SCEPS 危险化学品知识图谱问答评测（v1.1, 2026-11-17）

## 任务

分片文件里的内容按"组"排列。每组包含：
- 一个问题，以及它的标准答案（不可答题没有标准答案）；
- 若干个系统"输出"：来自不同系统或不同运行，已去重；系统名称对你隐藏（盲评）。

每个输出有两部分：
- **答案**：系统给出的回答；
- **证据**：系统返回的图谱事实或路径，写法为 `实体 -[关系]-> 尾实体`，多跳路径会连写。

你要给**每个输出**打一行标签。

判断依据只有四样：问题、标准答案、"标准答案在图谱中的位置"提示、该输出自己的证据。
- 不要用你自己的化学知识判断对错，以标准答案为准。
- 如果标准答案明显有误、与问题不符，标 `g=1`，但 `a` 仍然对照标准答案来判。
- "标准答案在图谱中的位置"由脚本自动定位，可能不完整或不准确，只作参考。

## 输出格式（JSONL，每个输出一行，键名固定）

```
{"id":"S3-1","a":"correct","h":0,"w":0,"e":1,"p":null,"g":0,"n":""}
```

| 键 | 含义 | 取值 |
|---|---|---|
| id | 输出编号，与分片中"--- 输出 X"一致 | 如 S3-1、M30-2、U12-3 |
| a | 答案标签 | 可答题：correct / partial / wrong / declined；不可答题：declined / answered |
| h | 幻觉 | 0 / 1 |
| w | 条件错误 | 0 / 1 |
| e | 证据正确 | 可答题 0 / 1；不可答题填 null |
| p | 路径完整 | 只有多跳题（M）填 0 / 1；单跳（S）和不可答（U）填 null |
| g | 标准答案存疑 | 0 / 1（不可答题一律 0） |
| n | 备注，30 字以内 | 下列情况必须写理由，其他情况留空 ""：a 为 partial、wrong 或 answered；h、w、g 任一为 1 |

---

## 一、可答题（S = 单跳，M = 多跳）

### a：答案标签（四选一）

- **correct**：覆盖标准答案的全部要点。以下情况都算 correct：
  - 同义改写；
  - 数值格式不同（空格、单位写法、全角/半角、"+"号、"≤"与"不大于"）；
  - 附带了不与标准答案矛盾的额外信息；
  - 列出多个候选，其中包含标准答案。
  - 例：标准答案"雾状水"，答案"可选用雾状水、泡沫、干粉" → correct。
- **partial**：只覆盖部分要点。包括两种情况：
  - 标准答案由"；""/""、"连接多个要点，答案缺了一部分；
  - 答了一部分，同时声明其余部分证据不足。例：标准答案"1.6～8.8%"，答案"爆炸下限 1.6%，上限证据未提供" → partial。
- **wrong**：与标准答案不符或矛盾；或者答的是别的字段、别的实体、别的条件下的内容。
- **declined**：明确表示证据不足或无法回答，而且没有对所问内容给出实质答案（附带一些相关事实也仍算 declined）。

**单数开放式问题（v1.1 补充）**

适用条件：问题只要求给出"一个 / 一种 / 一项 / 其中之一"，例如"一个燃烧产物是什么""可采取的一项应急处置措施""可选用哪种灭火剂"，而该字段在图谱中有多个取值。

判定规则：
- 答案给出的项目，只要在**该输出的证据**中有"正确实体 + 正确字段"的事实支持，就判 correct，即使它不是标准答案里的那一个。
  - 例：标准答案"二氧化碳"，答案"一氧化碳"，证据有"X -[燃烧产物]-> 一氧化碳" → correct。
  - 例：标准答案"雾状水"，答案"二氧化碳、泡沫"，证据有"X -[推荐灭火剂]-> 二氧化碳" → correct。
- 这种情况下 e 也按"证据中是否有支持该答案的正确事实"来判。
- 如果给出的项目在证据中找不到，判 wrong，并且 h=1。
- 问题要求列出全部（如"有哪些""包括哪些"）时，不适用本规则，仍按要点覆盖判 correct / partial。

**只复述了中间环节**

问题问的是某个后果、依据或措施，答案却只复述了中间环节（例如只说"属于吸入危害,类别1"），没有给出所问的内容 → wrong（不算 partial）。

**内容对、依据的对象错**

答案内容和标准答案一致，但依据的是化学品自身的字段，而不是问题要求的中间对象（例如禁配物、燃烧产物、某危险性类别）的字段 → a 按内容判（可以是 correct），同时 w=1、e=0、p=0。

### h：幻觉（0/1）

只看"答案中的实质性断言能否在**该输出自己的证据**中找到依据"。

h=1 的情况：
- 断言了证据里没有的事实（来自模型自身知识或编造）。即使内容碰巧正确，也算 1。
- 把证据中 A 实体或 A 字段的事实，说成是 B 实体或 B 字段的。
  - 例：证据是"叔丁醇 -[熔点]-> 25.3℃"，答案说"其燃烧产物一氧化碳的熔点是 25.3℃" → h=1。
- 从证据里的类别名推出证据中没有的具体内容。
  - 例：证据只到"吸入危害,类别1"，答案写出"吞咽及进入呼吸道可能致命" → h=1。

h=0 的情况：
- 答案内容都能在证据中找到依据（允许合理改写、汇总、加连接词）；
- a=declined 时一律 h=0。

### w：条件错误（0/1）

w=1：答案（或它所依据的证据）针对的不是问题所问的对象或条件。包括：
- **实体替换**：
  - 问"X 溶液 / X 母液 / X 固体 / X 钢瓶 / 某浓度的 X"，答案用的是 X 本身的信息；
  - 问"溴化乙锭"，答案用的是"溴"。
- **条件不符**：危险性类别、物理形态、浓度、暴露途径或场景与问题不一致。
- **证据归属错误**：问"X 的燃烧产物（或禁配物）的某个属性"，答案给的是 X 自己的该属性。
- **答了另一个字段**：问"灭火剂"答"灭火方法"；问某危险性类别对应的"预防措施"，答的却是化学品自己的"操作注意事项"。

w 和 a 相互独立。如果内容碰巧和标准答案一样，但依据的对象是错的：a 按内容判，同时 w=1。

### e：证据正确（0/1）

- e=1：该输出的证据中至少有一条事实**针对正确的实体和字段**，并且支持标准答案（全部或部分要点）。
- e=0：没有这样的事实；证据为"（无）"时也是 0。

### p：路径完整（只有多跳 M 填写；0/1）

多跳题要求的路径是：化学品 → 中间环节（如危险性类别、燃烧产物、禁配物）→ 目标字段。

- p=1：证据中有一条路径（或几条路径拼起来）经过了问题要求的中间环节，并沿目标字段到达包含标准答案（至少一个要点）的尾实体。可以参考"标准答案在图谱中的位置"。
- p=0：以下任一情况：
  - 路径跳过了中间环节（例如直接用了化学品自己的字段）；
  - 路径停在中间环节；
  - 路径没有到达标准答案。
  - 即使答案文字碰巧正确，只要路径跳过了中间环节，p 仍然是 0。

### g：标准答案存疑（0/1）

只有在很有把握时才标 1，并在 n 里说明理由。
- 例：问某化合物的英文名，标准答案却是另一个化合物的英文名。

## 二、不可答题（U）

这些问题所需的信息在图谱中**不存在**。常见两类：
- 问的是图谱里没有的配方、形态或物品，如"X 溶液""X 母液""X 钢瓶"；
- 问的是图谱不会记录的信息，如人员、时间、供应商、内部流程。

各字段这样填：
- **a**（二选一）：
  - **declined**：明确说图谱或证据中没有、无法确定、无法回答；或者给出"图谱中未列出 / 不存在"这类否定结论。附带相关事实、但没有断言所问内容的答案 → 仍是 declined。
  - **answered**：对所问信息给出了实质性回答。包括：带保留的肯定回答、用替代实体或相近字段的信息作答、回答"存在 / 有"。
- **h**：a=answered 时 h=1；a=declined 时 h=0。
- **w**：a=answered，并且用了替代的实体、形态或字段的信息作答 → w=1；否则 w=0。
- **e、p** 填 null；**g** 填 0。

## 三、示例

**例 1（单跳）**
- 问题："(异)戊酸发生火灾时，可选用哪种灭火剂？" 标准答案："雾状水"。
- 答案"可选用雾状水、泡沫、干粉"，证据是三条"推荐灭火剂"事实
  → `{"a":"correct","h":0,"w":0,"e":1,"p":null,"g":0,"n":""}`

**例 2（多跳）**
- 问题："1-癸烯被归到易燃液体,类别3的危险性类别后，个人防护装备应怎么配？"
- 标准答案："戴防护手套/穿防护服/戴防护眼罩/戴防护面具。"
- 输出 A：答案"身体防护应穿防静电工作服"，证据"1-癸烯 -[身体防护]-> 穿防静电工作服"
  → `{"a":"partial","h":0,"w":1,"e":0,"p":0,"g":0,"n":"只答防护服；用了化学品自身字段而非类别的防护要求"}`
- 输出 B：证据"1-癸烯 -[危险性类别]-> 易燃液体,类别3 -[防护要求]-> 戴防护手套/穿防护服/戴防护眼罩/戴防护面具。"，答案复述了这四项
  → `{"a":"correct","h":0,"w":0,"e":1,"p":1,"g":0,"n":""}`

**例 3（多跳，证据归属错误）**
- 问题："叔丁醇燃烧产物的熔点是多少？"
- 答案"25.3℃"，证据"叔丁醇 -[燃烧产物]-> 一氧化碳；叔丁醇 -[熔点]-> 25.3℃"
  → `{"a":"wrong","h":1,"w":1,"e":0,"p":0,"g":0,"n":"把叔丁醇的熔点当成燃烧产物的"}`

**例 4（不可答）**
- 问题："亚硝酸钠溶液……对应的危险货物类别是什么？" 答案用亚硝酸钠的"第5.1类氧化剂"作答
  → `{"a":"answered","h":1,"w":1,"e":null,"p":null,"g":0,"n":"用亚硝酸钠替代亚硝酸钠溶液"}`
- 问题："环氧乙烷用于灭菌时，图谱里是否列出了灭菌残留限量？" 答案"未列出……仅记录了操作注意事项"
  → `{"a":"declined","h":0,"w":0,"e":null,"p":null,"g":0,"n":""}`

---

## 四、注意事项

1. 每个输出独立判断，只看它自己的证据。同组内的输出可能很像，仍要逐个判断。
2. 不要因为答案长、语气自信就判 correct，一切以标准答案为准。
3. 不要读取 `id_map.json` 或其他分片（保持盲评）。
4. 备注 n 用简短中文。
